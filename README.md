# Greenfield School & College — new website (preview)

Three design versions of a new website for Greenfield School & College (GFSC), Mirpur-10, Dhaka.

- `v1-aurora/` — modern glass design
- `v2-heritage/` — calm editorial design
- `v3-bento/` — playful card design
- `shared/` — content in 4 languages, editable data, interactive campus map
- `admin/` — editor for notices, news, albums, teachers and staff
- `docs/` — research, content checklist and the edit guide (PDF)

Static site: no server or database needed.
