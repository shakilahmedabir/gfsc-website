২. প্রথমবার: GitHub সংযোগ (একবারই করতে হবে)

  1. github.com-এ লগইন করুন → উপরে ডানে ছবিতে ক্লিক → Settings → নিচে Developer settings → Personal access tokens → Fine-grained tokens → Generate new token।
  2. নাম দিন: gfsc-editor। Expiration: ১ বছর।
  3. Repository access → Only select repositories → gfsc-website বেছে নিন।
  4. Permissions → Repository permissions → Contents → Read and write।
  5. Generate token চাপুন → লম্বা কোডটি কপি করুন (পরে আর দেখা যাবে না)।
  6. এডিটর খুলুন (…/admin/) → উপরে ⚙️ GitHub সংযোগ → Owner: shakilahmedabir, Repository: gfsc-website, Branch: main, Token: কপি করা কোড → সেভ।
🔒 টোকেনটি পাসওয়ার্ডের মতো। কাউকে দেবেন না। এটি শুধু আপনার কম্পিউটারের ব্রাউজারে সেভ থাকে। অন্য কম্পিউটারে এডিট করতে সেখানে আবার সেট করতে হবে। হারিয়ে গেলে GitHub থেকে টোকেন মুছে নতুন বানান।

৩. এডিটর দিয়ে কাজ করা (সবচেয়ে সহজ)

এডিটরের উপরে ৫টি ট্যাব: 📢 নোটিশ · 📰 খবর/স্ট্যাটাস/পোস্ট · 🖼️ অ্যালবাম/গ্যালারি · 👩‍🏫 শিক্ষক · 🧑‍💼 স্টাফ। প্রতিটির নিয়ম একই:

  1. ট্যাব বেছে নিন → ＋ নতুন যোগ করুন (নতুনটি তালিকার একদম উপরে আসবে)।
  2. ডান পাশের ঘরগুলো পূরণ করুন। বাংলা ও English অবশ্যই লিখুন; আরবি/জার্মান খালি থাকলে ইংরেজি দেখাবে।
  3. পুরোনোটি বদলাতে ✏️, মুছতে 🗑, ক্রম বদলাতে ↑ ↓ চাপুন।
  4. শেষে উপরে সবুজ 🚀 Publish চাপুন। ১–২ মিনিট পরে ওয়েবসাইটে দেখা যাবে (পেজ রিফ্রেশ করুন)।

📢 নতুন নোটিশ

  • তারিখ, শিরোনাম (বাংলা + English), PDF লিংক (ঐচ্ছিক)।
  • “ওয়েবসাইট খুললেই পপ-আপ দেখাবে” টিক দিলে নোটিশটি ওয়েবসাইটে ঢোকার সাথে সাথে পপ-আপ হবে এবং “জরুরি” ব্যাজ পাবে। পুরোনো জরুরি নোটিশের টিক তুলে দিন।

📰 খবর / স্ট্যাটাস / পোস্ট

  • ধরন: news (খবর), status (ছোট আপডেট), post (সাধারণ পোস্ট)।
  • শিরোনাম, বিস্তারিত, ছবি (কম্পিউটার থেকে বাছলে নিজে থেকেই আপলোড ও ছোট হবে), “আরও পড়ুন” লিংক।
  • হোম পেজে সর্বশেষ ৩টি, আর “নোটিশ” পেজে সবগুলো দেখায়।

🖼️ নতুন অ্যালবাম / গ্যালারি

  • আকর্ষণীয় নাম দিন (যেমন: “উড়ে চলার ডানা — এইচএসসি বিদায় ২০২৭”), বছর, বিবরণ।
  • ছবি যোগ: কম্পিউটার থেকে একসাথে অনেক ছবি বাছুন (আপলোড হবে), অথবা ছবির লিংক প্রতি লাইনে একটি দিয়ে “＋ লিংক যোগ”।
  • প্রথম ছবিটি হবে অ্যালবামের কভার। ছবির উপরের × দিয়ে মুছুন।
  • ওয়েবসাইটে ছবিতে ক্লিক করলে একই পেজে কালো ব্যাকগ্রাউন্ডে বড় করে খুলবে — আগে/পরে, বন্ধ ও অ্যালবামের তথ্যসহ।

👩‍🏫 শিক্ষক / 🧑‍💼 স্টাফ

  • নাম, পদবি, বিভাগ (বিষয় অনুযায়ী ফিল্টার হয়), দায়িত্ব ও যোগ্যতা (প্রতি লাইনে একটি), ছবি।
  • ছবি না থাকলে নামের আদ্যক্ষর দিয়ে সুন্দর আইকন দেখাবে।
  • নিরাপত্তার জন্য মোবাইল নম্বর ও রক্তের গ্রুপ ওয়েবসাইটে দেখানো হয়নি।

৫. সমস্যা হলে

  • Publish-এ 401/403: টোকেনের মেয়াদ শেষ বা Contents “Read and write” দেওয়া নেই — নতুন টোকেন বানান।
  • Publish-এ 404: Owner / Repository নাম ভুল।
  • পরিবর্তন দেখা যাচ্ছে না: ২ মিনিট অপেক্ষা করে Ctrl + F5 চাপুন।
  • ওয়েবসাইট সাদা দেখাচ্ছে: হাতে এডিট করা ফাইলে কমা/উদ্ধৃতি ভুল হয়েছে — GitHub-এ ফাইলের History থেকে আগের ভার্সন ফেরত আনুন।
  • ছবি আসছে না: লিংক https:// দিয়ে শুরু কিনা দেখুন, অথবা ছবিটি আবার আপলোড করুন।
